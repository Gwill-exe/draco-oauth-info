hermes-email-bot

Draco is a privately operated, personal-use AI assistant built with Hermes Agent. The Google OAuth application is named hermes-email-bot.

Purpose

The assistant helps its owner read, organize, draft, and send Gmail messages and view and manage Google Calendar events, using permissions granted by the owner. Actions are subject to the owner's instructions and applicable approval requirements.

This is not a public signup service. This website only provides information about the integration; it does not offer login, collect Google authorization codes, or connect visitors' accounts.

Google access

Google account access is authorized through Google's consent flow. Publishing these informational pages does not grant access to any account.
